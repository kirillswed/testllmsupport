# Фактические затраты времени

Время местное: Asia/Tbilisi (UTC+4), 22 сентября 2026.

- До начала реализации: примерно 1 час по сообщению автора. Детальная разбивка
  этого времени неизвестна.
- 15:12–15:27: подготовка окружения, схемы, клиенты API, SQLite, обработка,
  эталон, тесты и README. Сюда вошли исправления и проверка живого валютного API.
- 15:27–15:30: проверка (24 теста), проверка CLI, числа входных файлов
  и дубликатов, оформление результатов. Снимок реального валютного API:
  `submission/fx_live_check.json`.
- 15:30–15:35: реальный прогон бесплатного маршрутизатора, оценка его ошибок,
  уточнение промпта и диагностики. Ключ предоставлен автором локально.
- 15:35–15:39: по запросу автора добавлена GLM 5.2; бесплатный endpoint проверен,
  после ошибок 429 проверены лимиты и выбран обычный платный endpoint.
- 15:39–15:43: успешный полный прогон GLM 5.2, 100% на заданной выборке,
  проверка повторного запуска, итоговые 28 тестов, отчёты и документация.
- Базовая реализация и интеграционные проверки: около **1 часа 20 минут**.
- Review LLM-пути и усиление безопасности: около **2 часов**. Основное время ушло
  на анализ trust boundary, проверку обходов keyword-фильтра, adversarial-сценарии,
  безопасную упаковку свободного ввода, локальную валидацию и повторные тесты.
- Общая фактическая оценка работы: **немного больше 3 часов**. Это включает
  первоначальный час, реализацию, реальный прогон и security review.
- Общая стоимость LLM в проведённых прогонах: **$0.00382280904**.
- 16:15–16:20: security review LLM-пути. Добавлены явная trust boundary для
  свободного текста, JSON-envelope с экранированием тегов, профили возможностей
  моделей, fingerprint контракта и `--refresh-cache`.
- После review: **36 тестов проходят**; добавлены adversarial cases для fake roles,
  nested JSON, spoofed closing tags, пробелов, base64 и HTML-комментариев.

Основная часть времени была потрачена на review и усиление безопасности LLM,
а не на добавление новых функциональных возможностей.
